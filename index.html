Генератор счет-фактур для заказов Корзинки

Загрузите файл формата “Заказы с товарами - АСОСИЙ.xls”. Программа разделит заказы по магазинам, объединит одинаковые товары и выгрузит счет-фактуру в Excel точно по шаблону “ШАБЛОН СЧФ для КОРЗИНКИ-365.xlsx”.

Загрузите Excel-файл

В файле обычно есть колонки Магазин, Название, Общая сумма, Товар, Кол-во, Цена за единицу, Стоимость, НДС, Стоимость с учётом НДС. Эти заголовки будут найдены автоматически.

    Как работает анализ?

    • Название магазина берется из колонки Название; одинаковые магазины объединяются.
    • Товары читаются из строк после заголовка Товар.
    • Значения Кол-во, Цена за единицу, Стоимость, НДС и Стоимость с учётом НДС переносятся в счет-фактуру без обрезания последних цифр.
